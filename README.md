# ДекорПрестиж — интернет-магазин входных дверей

Демонстрационный проект на Next.js 14 + React + TypeScript. Стиль использует переданный логотип «ДекорПрестиж» и минималистичную чёрно-белую палитру.

## Запуск локально

Требуется Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Затем откройте `http://localhost:3000`. Для сборки используйте `npm run build`, для production-режима `npm run start`.

## Каталог и цены

- `src/data/products.json` — 393 позиции в рабочей выгрузке: товары из прайс-листа и варианты коллекций производителя. Это не гарантированно полный ассортимент фабрики; перед публикацией сверить актуальную цену, название и комплектацию по ссылке `sourceUrl`.
- `src/data/panels.json` — 84 внутренние панели из предоставленного прайс-листа.
- Для моделей с `panelRequired` «Да» цена рассчитывается как `(розничная цена базовой двери + розничная цена выбранной панели) × 1,25`, затем округляется вверх до следующей сотни рублей. Совместимость панелей пока не подтверждена, поэтому интерфейс показывает предупреждение.
- Для готовых вариантов с сайта панель автоматически не добавляется, чтобы избежать двойного учёта.

## Изображения

В каталоге используются только те изображения, которые удалось однозначно связать с конкретной карточкой производителя (на данный момент 3 точных URL). В остальных карточках намеренно показана заглушка «Фото модели уточняется»: не используйте концепт-изображения в качестве фотографий конкретных дверей. Баннер на главной — визуализация стиля магазина, а не карточка товара.

Перед коммерческой публикацией подтвердите право на использование оригинальных изображений производителя. В `next.config.mjs` разрешены изображения с `labirintdoors.ru`.

### Обновление оригинальных изображений

В интернет-среде можно выполнить `npm run catalog:images`. Скрипт использует только HTTPS-страницы `labirintdoors.ru`, ищет индивидуальную карточку по названию и записывает изображение только при высокой уверенности совпадения. Он не публикует товары автоматически. Доступность сайта и формат его страниц могут меняться; после синхронизации вручную проверьте полученные соответствия и права на изображения. На этой рабочей среде доступ к сайту с контейнера ограничен, поэтому скрипт не запускался здесь против производителя.

## Что нужно завершить перед запуском

1. Подтвердить актуальные цены и разрешение на коммерческое использование фотографий.
2. Заменить заглушки карточек реальными фотографиями каждой конкретной модели/отделки.
3. Утвердить связь моделей с совместимыми внутренними панелями.
4. Скопировать `.env.example` в `.env.local`, указать `NEXT_PUBLIC_STORE_EMAIL` и `NEXT_PUBLIC_STORE_PHONE` (это обязательные контакты магазина).
5. Подключить серверное сохранение заявок, CRM или рабочую почтовую интеграцию, а также политику конфиденциальности и условия продаж.
6. Настроить домен и хостинг. Сайт не развёрнут и заказов пока не принимает.

## Структура

- `src/app/page.tsx` — главная, каталог, карточка товара, выбор панели и список заявки.
- `src/app/globals.css` — адаптивные стили.
- `src/data/products.json` — каталог продуктов и ссылки на источники.
- `src/data/panels.json` — цены и названия панелей.
- `public/images/logo-dekor-prestizh.jpg` — логотип.
- `public/images/hero-door-concept.jpg` — концептуальный баннер; не использовать как фото товара.
